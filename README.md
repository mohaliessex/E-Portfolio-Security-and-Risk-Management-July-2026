# Security and Risk Management e-Portfolio

MSc Cyber Security, University of Essex Online. Module e-portfolio, July 2026 cohort.

Live site: https://mohaliessex.github.io/-e-portfolio---Security-and-Risk-Management/

The site is built by GitHub Pages (Jekyll). Page content lives in Markdown files: `index.md`, `units/`, `discussions/`, `projects/`, `development/`, `reflection.md` and `references.md`. Navigation is in `_data/nav.yml`. Original Word artefacts are in `assets/docs/`.
